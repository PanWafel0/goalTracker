# Słownik pojęć – GoalTracker

| Pojęcie | Skrót | Znaczenie | Nazwa w kodzie |
|---|---|---|---|
| Cel | | Obiekt z nazwą, typem, wartością docelową i kategorią | Goal |
| Wpis postępu | WP | Zapis wykonanej pracy z datą i wartością | ProgressEntry |
| Wartość docelowa | WD | Liczba, którą trzeba osiągnąć, by zakończyć cel | targetValue |
| Typ celu | | Liczbowy albo nawyk (tak/nie) | GoalType |
| Streak | | Liczba kolejnych dni z co najmniej jednym wpisem | streak |
| Status | | "W trakcie" albo "Zakończony" | GoalStatus |
